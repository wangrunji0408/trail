# 衔尾 · TRAIL

回合制贪吃蛇解谜游戏。**[在线游玩](https://wangrunji0408.github.io/trail/)**

方向键 / WASD 移动，Z 撤回，R 重来。花台、石碑、水井、书卷、开关与陶壶碰触生效；空格向前一步并输出，结果直接加入蛇身。手机提供相同操作的按钮。

提示牌全部放在角落或岔路，默认通关路线不会触发。牌子仅提示一项关键性质，不提供路线或解题步骤。

## 本地运行

需要 Node.js 22 或更新版本，无第三方依赖。

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run build
```

`dist/` 是独立静态站点，所有资源采用相对路径，支持 GitHub Pages 项目子目录。ES modules 需要 HTTP 服务，不能直接通过 `file://` 运行。

## 九个关卡

| 关卡 | 核心规则 |
| --- | --- |
| 初尝 | 初始仅头、尾两格，吃果后增加一格。 |
| 恰好 | 身体容量有限，需要选择输入。 |
| 折叠 | 主动绕到支路花台，碰触压缩三颗红果。 |
| 储物 | 保存至一块石碑；清空后去右侧踩开关，打开回路，再返回同一块石碑读回。 |
| 水井 | 井显示输入图案；碰触投入鲜果，在地图另一处产生回应。 |
| 新果 | 空格向前一步并生成金果；输入与输出都留在蛇身。 |
| 配方卷 | 未读取只显示卷名；读入占一格，并提供新的生成规则。 |
| 陶壶 | 切换到独立的小蛇，只带回花种。 |
| 组合 | 组合储存、重置、开关、子房间与生成。 |

## 实现与验证

- `src/engine.js`：状态引擎、自动机关、按位置储存、生成、嵌套房间与整步撤回。
- `src/levels.js`：关卡、角落提示牌、配方。
- `src/render.js`：程序绘制的 SVG 地图与符号。
- `src/app.js`：输入、提示牌浮层、配方渐进展开、声音、进度。
- `tests/game.test.js`：30 项测试，覆盖九关合法通关、全部提示牌可达、默认路线不触发提示、存储隔离、独立开关、生成与配方读取等。

存档按关卡 ID 保存当前关与通关记录，刷新重新开始当前关。声音默认关闭；没有外部字体、图片、遥测、后端或模型调用。

## 部署

推送 `main` 触发 `.github/workflows/pages.yml`：Node 22 测试 → 构建 → 上传 `dist/` → GitHub Pages。
