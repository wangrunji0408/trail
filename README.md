# 衔尾 · TRAIL

一条小蛇，七座庭院。一个关于携带、遗忘与留下的回合制解谜游戏。

**[在线游玩](https://wangrunji0408.github.io/trail/)**

方向键 / WASD 移动，空格与脚下的奇物交互，Z 撤回，R 重来，H 提示。手机提供方向按钮。每关三层提示，可以从「庭院手记」自由选关。没有倒计时，动作全部可撤销。

## 本地运行

需要 Node.js 22 或更新版本，无第三方依赖。

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run build
```

`dist/` 是可独立托管的静态站点。所有站内资源使用相对路径，支持 GitHub Pages 项目子目录。不要直接用 `file://` 打开：浏览器需要通过 HTTP 加载 ES modules。

## 七座庭院

| 庭院 | 新发现 |
| --- | --- |
| 初尝 | 果子会变成身体上的纹样，门认得它们。 |
| 恰好 | 鳞片有限，不必吃下所有果子。 |
| 折叠 | 三颗红果折成一枚红印，颜色仍在。 |
| 石头记得 | 白雨洗去果纹，石碑留住刻印。 |
| 井的另一端 | 井需要鲜果，红印没有汁液；回应要亲自拾起。 |
| 壶中天地 | 留下外面的蛇，用壶里的小蛇带回一枚花种。 |
| 花园深处 | 把已经学会的规则串成一条完整的路。 |

## 实现

- `src/engine.js`：纯状态引擎、动作校验、整体快照撤回、嵌套房间。
- `src/levels.js`：七个主庭院和壶内庭院的数据。
- `src/render.js`：程序绘制的 SVG 花园、物件、蛇身与纹样。
- `src/app.js`：键盘与触屏输入、三层提示、手记、声音与进度。
- `tests/game.test.js`：七关合法通关路径及容量、压缩、石碑、工具回执、嵌套返回、撤回等共 18 项检查。

存档只保留所在庭院和已通过的庭院；刷新会重置当前关的步数。声音默认关闭。没有外部字体、图片、遥测、服务端或模型调用。

## 部署

推送到 `main` 会触发 `.github/workflows/pages.yml`：Node 22 测试 → 构建 → 上传 `dist/` → GitHub Pages。仓库的 Pages source 需要设置为 GitHub Actions。

策划与概念映射见 [设计说明](docs/DESIGN.md)。其中包含机制剧透与面向创作者的技术说明，游戏界面不提供这个入口。
